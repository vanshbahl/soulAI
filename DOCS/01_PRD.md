# Product Requirements Document (PRD) - SoulAI

## 1. Executive Summary
**SoulAI** is a premium native iOS dating application built with native SwiftUI. It re-imagines matchmaking by pairing artificial intelligence personality synthesis with an editorial, photography-first user interface inspired by Apple HIG, Kinfolk, and high-end lifestyle design.

## 2. Core Value Proposition & Emotional Goal
- **Emotional Storytelling**: "AI understands your personality and helps you find meaningful connections."
- **Editorial Aesthetics**: Warm off-white canvas (`#FAF8F5`), crisp white surfaces, full-bleed portrait photography, serif typography, and a single distinctive coral/rose accent (`#FF5A7A`).
- **No Clutter / Anti-Dashboard**: Replaced long paragraphs and robotic explanation boxes with short emotional quotes, 3-4 personality tags, and intuitive natural conversations.

## 3. Five Primary Application Tabs
1. **Discover (`DiscoverView`)**: Hero screen featuring 75% full-bleed portrait cards, name/age, occupation/location, 3-4 tags, an elegant quote, and bottom floating action controls (Reject ✕, Like ♡, and AI Insight ✦).
2. **Matches (`MatchListView` & `MatchDetailView`)**: Clean grid of high-resonance connections and deep relationship synergy profiles.
3. **Conversations (`ConversationsListView` & `AIChatView`)**: iMessage-style clean white chat with discreet floating `"Need help replying? ✨"` assistant providing 3 natural suggested replies in a sleek bottom sheet.
4. **AI Coach (`DatingCoachView`)**: Warm relationship companion titled *"Your Dating Companion"* with quick prompt chips (*"Help me start a conversation"*, *"Make my reply more playful"*, *"Understand this message"*) and live guidance stream.
5. **Profile (`ProfileView`)**: Minimalist profile featuring a large circular portrait, name, personality essence summary (*"Creative explorer"*), 3 clean interest tags, and relationship intentions.

## 4. Emotional Match Experience
When users match, SoulAI presents a focused emotional celebration modal (*"It's a Match ❤️"*), displaying overlapping circular portraits, compatibility percentage, and a single shared emotional insight sentence.
